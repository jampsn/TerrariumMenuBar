## 1. 核心目标与设计边界

在现有 4 口基础生态缸（温润苔原 `.meadow`、暖阳沙地 `.sand`、热带雨林 `.rainforest`、碧波鱼缸 `.aquatic`）之外，新增第 5 种**隐藏生态缸：深蓝珊瑚礁海缸（`.reef`）**。

1. **主线里程碑解锁条件（严禁跳过）**：
   - 必须**同时拥有全部 4 种基础生态缸**（当前 `saveData.containers` 包含 `.meadow`、`.sand`、`.rainforest`、`.aquatic`）；
   - 且**基础 31 种动物/奇遇生物图鉴已全收集**（25 种可交互动物 + 6 种空中奇遇生物全部在 `unlockedCodexIDs` 中）；
   - 未满足前，买缸面板显示神秘锁定槽位 `???`（提示已达成进度如 `缸体 X/4 · 动物 X/31`）；满足后正式开放购置（基价 **65 生态点**，走现有槽位阶梯定价与 `75%` 拆缸退点）。
2. **「52 项基础全收集」与「隐藏图鉴 `???`」完全解耦**：
   - 原有主线成就 `ach_codex_52`（「全生态宗师」）与图鉴主计数保持 **52 项**不变，绝不破坏既有全收集成就的达成口径；
   - 海缸新增的 **11 项隐藏物种**（5 种珊瑚 + 6 种海洋生物）在图鉴中归入独立的**「隐藏海域图鉴（X/11）」**区块：
     - **未解锁时**：统一显示为 `🔒 ??? · 未知海域物种`（隐藏真实名称、解锁条件与生态描述，仅保留神秘剪影提示，绝不剧透）；
     - **解锁后**：即时显形完整名称、解锁条件、描述与 `+2 / +3 / +5` 生态点奖励；
   - 新增 2 项隐藏成就：`ach_reef_unlock`（解锁深蓝海缸）与 `ach_reef_master`（海缸 11 项隐藏物种全收集）。

## 2. 海缸物理仿真闭环（盐度 + 溶氧 + 温度）

1. **新增持久化字段**：
   - 在 `TerrariumInstanceState` 新增 `public var salinity: Double?`（`Codable` 使用 `decodeIfPresent` 保持 `v1~v5` 老存档 100% 无损兼容）；
   - 非海缸保持 `nil`；海缸初始化默认 **`35.0‰`**，允许安全范围 `28.0~40.0‰`，最佳适宜区间 **`32.0~36.5‰`**。
2. **蒸发浓缩 → 补淡水稀释 / 撒海盐微调**：
   - **蒸发浓缩**：随水分自然蒸发（`evaporationPerHour`），海缸盐度会缓慢升高浓缩（约 **`+0.30‰/h`**，开启加热棒/高温时约 `×1.35`）；放置「活石拱门」摆件可减缓盐度波动 `30%`；
   - **补淡水（RO水）**：海缸下方的原「换水打氧」主按钮变为**「补淡水」**（提升溶氧 `+12%`，同时稀释盐度 **`-1.2‰`**）；
   - **撒海盐微调**：右侧传感器卡片右下角提供 **`🧂 +1.5‰`** 快捷按钮（不消耗点数，防补水过头，提升盐度 `+1.5‰`）；
   - **溶氧与温度**：复用 `humidity` 作为溶氧量（最佳 `65~95%`）；水温最佳 **`23~27°C`**（`73~81°F`），沿用现有水下加热棒与降温扇。
3. **温和失衡表现**：
   - 当盐度 `<32.0‰` 或 `>36.5‰`、或溶氧 `<45%` 时，珊瑚进入 `.wilting` 状态：画面显示为**低饱和度白化/缩触手**，选中卡片分别显示精准提示：**「盐度过浓 / 盐度过淡 / 缺氧」**；恢复正常后重新舒展。

## 3. 珊瑚、造景摆件与海洋生物阵容

### 3.1 珊瑚培育（5 种，复用 `PlantInstance` 与 4 态精灵表）
| ID | 名称 | 解锁/繁衍核心条件 |
| :--- | :--- | :--- |
| `coral_zoanthid` | 绿纽扣珊瑚 | 海缸冷启动先锋珊瑚（补淡水/达标即可萌发） |
| `coral_acropora` | 红鹿角珊瑚 | 盐度 `32.5~36.0‰` + 溶氧 `≥75%` + 活石拱门 |
| `coral_brain` | 荧光脑珊瑚 | 绿纽扣 `≥1` + 水温 `24~27°C` |
| `coral_anemone` | 千手佛海葵 | 绿纽扣 `≥1` + 溶氧 `≥70%` |
| `coral_seafan` | 紫海扇 | 造浪泵开启 + 盐度 `32.5~36.0‰` |

### 3.2 珊瑚石与功能摆件（5 种，遵循 PM-12 2:1 V形底边）
- `reef_live_rock`（活石拱门，`3×2`）：减缓盐度波动 `-30%`，加速珊瑚钙化生长；
- `reef_wavemaker`（迷你造浪石/泵，`2×2`）：减缓溶氧流失 `-25%`，解锁紫海扇与蓝吊鱼；
- `reef_coral_cave`（珊瑚礁洞，`2×2`）：小丑鱼与清洁虾的夜间庇护生态位；
- `reef_giant_clam`（五彩砗磲贝，`2×1`）：高阶钙质造景，`+10%` 产点加成；
- `reef_sand_shells`（白沙贝壳滩，`2×1`）：可踩踏贴地图层，海星与寄居蟹活动偏好区。

### 3.3 海洋生物（6 种，14 帧像素精灵表）
分为两大互不吞噬的食物链群落：
- **礁石共生群（`.reefSymbiosis`）**：
  1. **小丑鱼（`clownfish`）**：需拥有「千手佛海葵」或「活石拱门」解锁，中水层（`gz=14`）游动，闲逛时常驻海葵旁触发共生摇曳；
  2. **海星（`starfish`）**：贴底（`gz=0`）极慢速爬行，被动功能：**缓慢降低缸壁藻垢 `glassFogLevel`**；
  3. **清洁虾（`cleaner_shrimp`）**：贴底/礁石附近活动，被动功能：**减缓同缸生物饥饿速率**；
  4. **蓝吊鱼（`blue_tang`）**：需造浪泵 + 活石解锁，中上层（`gz=22`）巡游；
  5. **寄居蟹（`hermit_crab`）**：贴底（`gz=0`）背壳爬行，**受惊时立即缩入贝壳内**。
- **幽蓝独行群（`.reefSeahorse`）**：
  6. **海马（`seahorse`）**：需「紫海扇」解锁，中水层（`gz=12`）竖直悬停摆尾；为防止被大型鱼抢食，与蓝吊鱼/小丑鱼等自动互斥，切换时安全收纳进生物仓 `.stored`。
