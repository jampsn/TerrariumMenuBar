# 001 - 视觉透视、温控交互与 UI 布局精细化优化

> **关联版本**：`v0.2.1`（或 `v0.3.0` 迭代）  
> **状态**：已确认立项，开发中

---

## 一、需求清单与验收标准

1. **45° 等距背景图重构（Pass 0）**
   - **目标**：消除 `bg_room_day/night/rain/warm.png` 中正交水平的“墙面 + 桌面”双层硬分割线与色块断层。
   - **方案**：删除未使用的废弃资产 `terrarium_bg_*.png`；重绘 4 张 `bg_room_*.png`（`224×176`）为无硬分割线的柔和径向/斜向氛围渐变背景，底部仅保留极柔和的 45° 菱形环境投影。
2. **前玻璃框弱化精修**
   - **目标**：保留 45° 封闭容器边界与擦雾/除藻物理载体，但消除对前景生物与食盆的视觉切割。
   - **方案**：修改 `tank_front_glass.png`（`224×176`），移除正中央贯穿生物区的竖直棱线，柔化上沿两条斜线，保留底部菱形收边线与两侧短竖棱。
3. **升降温工具防连点刷温修复**
   - **目标**：消除 `toggleThermalMode` 连点 2 次（关→开）导致温度瞬时 `±2°C` 跳变的异常行为。
   - **方案**：移除 `TerrariumState.toggleThermalMode` 中的瞬时 `inst.temperature ± 2` 硬改，完全交由 `TerrariumSimulation.advanceInstance` 按稳态目标温度随时间渐进演进；在 UI 温度卡片与提示中明确显示目标稳态温度。
4. **睡莲水下茎/根阶段化优化**
   - **目标**：消除成熟期睡莲底部的横向“钉子”根爪与横穿水层的长绿茎对鱼群通透感的干扰。
   - **方案**：精修 `plant_lotus_stem.png` 去除底部横向根爪像素；在 `PixelStageView.swift` 中限制仅 `.sprout` 幼苗期以半透明（`0.5`）绘制水下细芽茎，`.mature` 成熟期与 `.withered` 枯萎期不再绘制水下茎与根部。
5. **UI 顶部缸按键与温度显示防遮挡**
   - **目标**：解决多缸切换按键与温度传感器卡片中文字被截断、换行挤压或与按钮重叠遮挡的问题。
   - **方案**：
     - 多缸切换条：`LazyVGrid` 最小宽度调整为 `116pt`（每行最多 3 个），温度数字添加 `.fixedSize()` 与 `.layoutPriority(1)`，缸名单行截断不挤压温度。
     - 传感器条：温度卡片适当增大横向空间占比，副标题单行缩略显示（含温控目标提示），温控按钮紧凑排版不与文本重叠。
6. **鱼缸藻垢立体化表现重构**
   - **目标**：移除横穿缸体的直角矩形半透明绿块，改为符合 45° 等距透视的“水体变绿 + 缸壁藻体”特征。
   - **方案**：
     - 沿用 `TerrariumConfig.isoToScreen` 计算鱼缸水体 45° 等距六边形轮廓（顶面 `gz=38` + 前左/前右立面至 `gz=0`），随 `glassFogLevel` 渐进叠加柔和藻绿水体染色；
     - 新增 `vfx_aquatic_algae.png`（`224×176`），贴合鱼缸后壁底角与前壁 V 形底棱绘制像素风点状/丝状绿藻斑块，并在 `TerrariumApp.swift` `--self-test` 资产清单中注册校验。
