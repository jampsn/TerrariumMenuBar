# Feature 005: v0.3.0 第二阶段 — 自定义命名、4x 无损像素快照、多缸生态共鸣与晨昏微叙事

> 关联基线：[BASELINE.md](../BASELINE.md) | 路线图：[ROADMAP.md](../ROADMAP.md)

## 1. 目标与范围
在 `v0.3.0` 第一阶段（像素图标、50 项图鉴、里程碑称号与缸框皮肤）的基础上，落地轻度克制型交互与陪伴深化能力：
1. **自定义生态缸名称与生物昵称**：允许玩家随时在 UI 中重命名当前生态缸和已领养的小动物（持久化于 `TerrariumContainer.customName` 与 `CritterPersistentState.nickname`）。
2. **一键 4x 无损像素快照导出**：使用 `ImageRenderer` 对舞台进行 `4x` 整数倍率（`896 × 704`）无模糊渲染，附加缸名、称号与日期像素角标，经 `NSSavePanel` 保存为 PNG。
3. **多缸轻度生态共振与空中物种串门**：存档内拥有 `≥ 2` 种不同生态类型的活跃未休眠缸时，触发跨缸生态共鸣（植物萌发概率 `+10%`，多缸效率补偿 `+5%`）；已解锁的空中奇遇物种可在适当时段跨缸短暂串门飞舞。
4. **晨昏光影过渡与 Lv.5 挚友微叙事**：`06:00~07:30`（日出）与 `17:30~19:00`（日落）叠加柔和暖金光晕；`Lv.5` 挚友生物结合本地室外气温与昵称弹出微叙事小气泡。

## 2. 数值与防呆约束
- 严禁在 `MenuBarPopoverView.swift` 中使用 SwiftUI `@State` 宏（CommandLineTools 环境下 `SwiftUIMacros.StateMacro` 不可用），所有编辑草稿与弹窗状态统一托管在 `TerrariumState` 的 `@Published` 属性。
- 多缸生态共鸣效率补偿 `+5%` 仅对槽位效率生效，且总效率上限封顶 `1.0`（不得超过首缸 `100%`）。
- 串门空中物种纯属视觉表现，不占生物槽位，不触发原生生态外的图鉴解锁。
- 命名限制长度 `1~16` 字符，过滤首尾空白，空字符串直接忽略以防 UI 排版溢出。

## 3. 验收标准
- 新增核心单元测试（覆盖生态共鸣判定、多缸效率封顶、晨昏光晕系数与挚友微叙事输出）全绿通过。
- `bash build_app.sh` 零 Swift 编译警告通过，`--self-test` 全量通过。
