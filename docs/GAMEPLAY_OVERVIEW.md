# 《Pixel Terrarium（像素生态箱）》游戏玩法全览（v1.0.0 正式版）

> 本文档严格核对自 `TerrariumMenuBar`（`v1.0.0`）源码，全面梳理核心循环、四类生态缸、52 项物种图鉴、14 项组合式成就称号、20 件造景摆件与 5 款缸框皮肤、日常照料与温控系统、经济防刷机制及 UI 交互。

## 一、核心玩法循环与菜单栏驻留体验

1. **菜单栏常驻形态**
   - 应用以纯菜单栏模式运行（无 Dock 图标，支持设置页一键开关开机自启），点击菜单栏图标展开 `472pt` 宽像素风 Popover 窗口（顶边锁定贴合菜单栏下方，仅向下方伸展，Popver 收起自动暂停 15fps 渲染省电）。
   - 舞台画布为 `224 × 176` 逻辑像素（2x 整数缩放为 `448 × 352 pt`），基于 `11 × 11`（`col/row: 0...10`）2:1 等距网格与多 Pass Y-Sort 渲染管线；左上角实时显示当前缸体独立培育天数 `Day X`，顶栏显示全局累计挂机天数 `Day X`。
   - **菜单栏 6 态动态图标**（按优先级判定）：`sleep`（休眠）> `event`（天气事件或新图鉴提醒）> `dry`（湿度/溶氧低于干涸阈值）> `hungry`（有在缸生物、食盆/浮圈余粮为 0 且至少 1 只饥饿 `≥60`）> `night`（深夜星月）> `normal`。

2. **开箱即用与冷启动破冰**
   - **Day 0 初始存档**（`save.json`，`schemaVersion = 5`，写入前自动轮转 `.json.bak` 备份且支持损坏隔离恢复）：默认自带 1 口免费「苔原缸 #1」（`.meadow`），初始 **5 生态点**，空缸无植物无动物，初始 `22°C`、湿度 `35%`、氛围 `.day`。
   - **冷启动破冰机制**：每口缸**终身仅限 1 次** `15s` 冷启动植物萌发脉冲。手动「喷水加湿 / 换水打氧」每次增加 `+12%` 湿度并推进脉冲 `+8.0s`，湿度达标且推进满 `15s` 即 100% 破土长出该生态缸的基础首株植物。

3. **后台 Tick、离线结算与休眠模式**
   - **后台 Tick**：每 **30 秒** 触发一次多缸并行演进；前台舞台动画以 **15fps** 独立运行。
   - **离线结算**：重新打开应用时自动对存档内**全部未休眠生态缸**独立结算，单次离线结算上限 **8 小时**（`28800s`，前 `4 小时`全速、第 `4~8 小时`产点半衰），按 `≤60s` 步长推演蒸发、温度回归、生态产点、植物生长/枯萎/萌发、生物饥饿、离线代偿进食、图鉴解锁与天气事件。
   - **休眠模式**：点击「休眠」合上像素玻璃盖，立即暂停该缸的后台 Tick、离线结算、水分蒸发、饥饿累积、天气事件与植物生长；鱼缸游鱼沉至底层悬停休眠。

## 二、四种生态缸体类型与跨缸生态共鸣

全 4 种缸体均已开放购置，最多同时拥有 **9 口**（3×3 按键网格），多缸状态完全隔离、支持自定义改名与 `75%` 折旧拆缸退点。
- **阶梯购置定价**：第 2 口缸起按基础价购买，之后每多 1 口 `+15` 点：`baseCost + max(0, existingTankCount - 1) * 15`。
- **多缸轻度生态共鸣**：存档内同时存在 `≥2` 种不同生态的活跃未休眠缸时，自动激活「✨共鸣」：植物常规萌发概率 `+10%`，多缸槽位产点效率补偿 `+5%`（总效率封顶 `1.0`），并触发空中奇遇物种跨陆缸串门。

## 三、完整物种图鉴与演化规则（共 52 项）

### 3.1 植物系统（21 种：前置首株必出 + 动态权重池）
- **通用规则**：单缸植物上限 **`12` 株**；常规脉冲每 **`600s`** 检测一次；`300s` 成熟；图鉴首次解锁 **`+2` 点**。
- **两段式萌发机制**：
  1. **前置组合首株 100% 必出**：凡满足对应温湿度/造景/母株条件的物种，只要当前缸内数量为 `0`，即在下次脉冲 `100%` 必定长出首株，彻底消除看脸阻塞；
  2. **后续动态权重池**：已达标物种均有首株后，由所有符合条件且未满上限的物种组成动态权重池随机抽选萌发，木质/藤架摆件提供 **`×1.5`** 加成。
- **生态分布**：
  - **苔原 (6)**：绒球苔藓 (`moss`)、卷叶蕨 (`fern`)、幸运三叶草 (`clover`)、红菇 (`red_shroom`)、茅膏菜 (`sundew`)、微光菇 (`glow_shroom`)
  - **沙地 (5)**：莲座多肉 (`succulent`)、星点芦荟 (`aloe`)、金琥仙人球 (`cactus`)、生石花 (`lithops`)、蓝叶龙舌兰 (`agave`)
  - **雨林 (5)**：龟背竹 (`monstera`)、积水凤梨 (`bromeliad`)、热带兰花 (`orchid`)、猪笼草 (`pitcher_plant`)、孔雀竹芋 (`calathea`)
  - **水域 (5)**：莫斯藻球 (`marimo`)、皇冠水草 (`anubias`)、螺旋苦草 (`vallisneria`)、迷你水睡莲 (`lotus`)、红蝴蝶水草 (`red_ludwigia`)

### 3.2 可领养动物（25 种，生态点购买 + 食物链互斥 + 自定义昵称）
同缸仅允许同一 `FoodChainGroup` 的生物共存；冲突物种切换入缸时自动安全存仓（`.stored`），零互吃损耗；支持为每只动物起自定义昵称：
- **苔原**：微虫螺共生群（露珠蜗牛、迷你西瓜虫、七星瓢虫[支持地面爬行与 35% 概率低空振翅飞行]、栗壳独角仙）互斥 两栖领地（绿豆树蛙、红腹小蝾螈）
- **沙地**：沙漠甲虫共生群（琥珀甲虫、琉璃圣甲虫、沙漠枯叶螳）互斥 沙地捕食者（豹纹沙守宫、黄金沙蝎、沙漠角蜥）
- **雨林**：雨林拟态虫群（枯叶拟态脩、长戟大兜虫、蓝闪蝶）互斥 雨林捕食者（七彩高冠变色龙、蓝宝石箭毒蛙、红眼树蛙）
- **水域**：温顺鱼虾共生群（樱花米虾、红绿灯鱼群、熊猫鼠鱼、小精灵吸盘鱼、水晶红虾）互斥 半月斗鱼（单缸独养）互斥 天空蓝螯虾

### 3.3 空中奇遇物种（6 种，四大生态全覆盖 + 停落栖息 + 天敌扑空剧场）
无需购买、不占生物位，满足条件自然现身解锁图鉴（**`+5` 点**）；支持多向转向巡航、植物/摆件停落栖息，邻近天敌时触发「吐舌!/挥镰! + 溜了!」治愈系扑空逃逸动画：
1. **微光萤火虫** (`firefly`)：苔原 + 沉木 + 幸运草/蕨 + 夜/雨 + 湿度 `≥65%`
2. **月光小飞蛾** (`moon_moth`)：苔原 + 非枯萎微光菇 `≥1` + 夜晚 + 湿度 `≥72%`
3. **碧蓝蜻蜓** (`dragonfly`)：苔原或水域 + 日/暖阳 + 浅水洼/睡莲 + 湿度 `≥68%`（水域严格飞于水面 `gz >= 39.5` 之上）
4. **砂金蚁狮蛉** (`antlion_lacewing`)：沙地 + 日/暖阳 + `≥26°C` + 干燥(`≤48%`) + 叠石/风蚀拱 + 成熟沙地植物
5. **翠光夏蝉** (`luna_cicada`)：雨林 + 夜晚 + `≥26°C` + 藤蔓架 + 龟背竹 `≥1`
6. **翡翠兰花蜂** (`orchid_bee`)：雨林 + 日/暖阳 + 湿度 `≥72%` + 热带兰花/猪笼草 `≥1`

## 四、成就称号、皮肤与日常照料系统

1. **14 项组合式成就称号系统**：
   - 在「图鉴」Tab 顶部切换至「成就称号」可查看全部 14 项里程碑（5 阶图鉴称号、四象造景师、追风捕影客、蛙鸣三重奏、沙海三霸主、奇异捕虫师、水晶龙宫主、莫逆之交、万灵共主、框景美学师）。
   - 首次达成一次性奖励 **`+1 ~ +3` 生态点**，已解锁的任意称号支持点击自由佩戴（展示于图鉴顶栏与 4x 像素快照角标）。
2. **20 件造景摆件（每缸 5 件）与 5 款缸体边框皮肤**：
   - 造景摆件支持现场自由调整位置与收起；缸体边框皮肤（经典深绿、温润原木、复古黄铜、极简磨砂白、黑曜紫金）作为后期点数出口全缸通用。
3. **五阶好感度羁绊（`0~100`）与 Lv.5 挚友微叙事**：
   - 轻抚只加好感（`20 分钟`冷却、每日 `6 次`上限、0 点击直发点数），通过 Lv.3/Lv.5 性格特技反哺；轻抚 Lv.5 挚友时结合昵称与当地室外气温弹出暖心微叙事短句。
4. **晨昏过渡光影与 4x 无损像素生态快照**：
   - 日出（`06:00~07:30`）与日落（`17:30~19:00`）叠加柔和暖金渐变光晕；顶栏 `📸` 按钮支持导出 `896 × 704` 无损整数像素快照 PNG（含缸名、佩戴称号与日期角标）。

## 五、经济系统与防刷机制

- **挂机产点**：需缸内存在活体植物或在缸生物，且湿度达标（沙地 `≥26%`，其余 `≥35%`）。基础间隔 **`1200s`/点**，适宜环境 **`720s`/点**；多缸槽位递减（100% → 80% → 65% → 55% → 50%），离线前 4h 全速、4~8h 半衰。
- **防倒卖与防刷闭环**：全 25 种动物售价严格高于图鉴返点；幼苗修剪 0 返点；进食奖励 `3 小时`/只冷却；`.stored` 生物仓彻底隔离不消耗食物不产点。
