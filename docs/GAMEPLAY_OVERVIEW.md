# 《Pixel Terrarium（像素生态箱）》游戏玩法全览

> 本文档严格核对自 `TerrariumMenuBar`（`v0.2.0`）源码，全面梳理核心循环、四类生态缸、29 项物种图鉴、日常照料与温控系统、经济防刷机制及 UI 交互。

---

## 一、核心玩法循环与菜单栏驻留体验

1. **菜单栏常驻形态**
   - 应用以纯菜单栏模式运行（无 Dock 图标），点击菜单栏图标展开 `472pt` 宽像素风 Popover 窗口。
   - 舞台画布为 `224 × 176` 逻辑像素（2x 整数缩放为 `448 × 352 pt`），基于 `11 × 11`（`col/row: 0...10`）2:1 等距网格与多 Pass Y-Sort 渲染管线。
   - **菜单栏 6 态动态图标**（按优先级判定）：`sleep`（休眠）> `event`（天气事件或新图鉴提醒）> `dry`（湿度/溶氧低于干涸阈值：苔原 `<35%`、沙地 `<20%`、雨林 `<50%`、鱼缸 `<50%`）> `hungry`（有在缸生物、食盆/浮圈余粮为 0 且至少 1 只饥饿 `≥60`）> `night`（深夜星月）> `normal`。
   - **悬浮 Tooltip**：实时展示 `[休眠] 缸类型 · 温度°C · 湿度% · 食盆x/5 · 住民数`。

2. **开箱即用与冷启动破冰**
   - **Day 0 初始存档**（`save.json`，`schemaVersion = 4`）：默认自带 1 口免费「苔原缸 #1」（`.meadow`），初始 **5 生态点**，空缸无植物无动物，初始 `22°C`、湿度 `35%`、氛围 `.day`。
   - **冷启动破冰机制**：每口缸**终身仅限 1 次** `15s` 冷启动植物萌发脉冲。手动「喷水加湿 / 换水打氧」每次增加 `+12%` 湿度并推进脉冲 `+8.0s`，当湿度达标（苔原 `≥45%`、雨林 `≥60%`、鱼缸 `≥55%`、沙地自动满足 `≤55%`）且推进满 `15s`（连喷 2 次即触发）时，100% 破土长出该生态缸的基础首株植物。

3. **后台 Tick、离线结算与休眠模式**
   - **后台 Tick**：每 **30 秒** 触发一次多缸并行演进；前台舞台动画以 **15fps** 独立运行。
   - **离线结算**：重新打开应用时自动对存档内**全部未休眠生态缸**独立结算，单次离线结算上限 **8 小时**（`28800s`），按 `≤60s` 步长推演蒸发、温度回归、生态产点、植物生长/枯萎/萌发、生物饥饿、离线代偿进食、图鉴解锁与天气事件。
     - **离线代偿进食**：当单次推演总时长 `> 120s` 时，在缸生物若 `hunger ≥ 55.0` 且食盆余粮 `> 0`，会自动消耗 1 份粮，饥饿 `-45.0`（下限 0），并奖励 `+1` 生态点。
   - **休眠模式**：点击「休眠」合上像素玻璃盖，立即暂停该缸的后台 Tick、离线结算、水分蒸发、饥饿累积、天气事件与植物生长；鱼缸游鱼会沉至底层悬停休眠。

## 四、日常照料与工具系统

1. **四大核心照料按钮**
   - **喷水加湿 / 换水打氧**：湿度/溶氧 `+12%`，开启 `180s` 凝露加成；若陆生湿度 `≥72%` 会微量增加 `+0.03` 水雾；若湿度 `≥80%` 且温度 `>20°C` 会物理降温 `-1°C`；推进冷启动脉冲 `+8.0s`。
   - **食盆投喂 / 投放鱼粮**：向食盆/浮圈添加 1 份粮（上限 `5` 份），触发动物 A* 寻路进食（每口进食减 `45.0` 饥饿）。
   - **清理擦雾 / 擦净藻垢**：清零 `glassFogLevel`，并自动移除所有枯萎（`.withered`）植物（每清理 1 株枯植返还 **`+1` 点**）。
   - **休眠 / 唤醒**：合上/打开休眠盖。

2. **现场植物与摆件编辑**
   - 点击画布中植物：支持**「移栽」**（高亮绿色可种格，避开食盆/喂食圈净空区与摆件）与**「修剪」**（成熟/凝露/缺水植物返 **`+1` 点**，幼苗 `0` 点）。
   - 点击画布中摆件：支持**「移动位置」**（支持 `1×1`、`2×1`、`2×2`、`3×2` 动态占地校验）与**「收起」**。

3. **五阶好感度羁绊系统（`0~100`）**
   - **轻抚机制**：点击画布中动物进行轻抚，每次 **`+3` 好感**（饱腹状态 `hunger < 30.0` 时 **`+4` 好感**）。
   - **防刷与受惊**：单只冷却 **`20 分钟`**，单只每日有效轻抚上限 **`6 次`**，**0 点击直发点数**。`1.5s` 内连续点击达阈值（Lv.1~3 为 `3 次`，Lv.4+ 放宽至 `4 次`）会触发**受惊**，进入 **`60s` 缓神期**。
   - **五阶成长与性格特技**：
     - **Lv.1 初识 (`0~9`)** → **Lv.2 熟稔 (`10~29`)**（巡游主动前往专属摆件概率提升至 `45%`）→ **Lv.3 亲近 (`30~59`)**（激活性格特技 I）→ **Lv.4 信赖 (`60~99`)**（受惊阈值放宽至 `4 次`）→ **Lv.5 挚友 (`100`)**（金色心意 `💛` + 性格特技 II）。
   - **三系性格被动特技**：
     - **慢消化型**（慢性子、害羞团、静如叶、守沙者）：Lv.3 饥饿 `-10%`，Lv.5 饥饿 **`-20%`**。
     - **共振加速型**（护木侠、勤劳钳、角力士、缸霸、追光手）：Lv.3 全缸产点 `+5%`，Lv.5 **`+10%`**。
     - **灵动陪伴型**（爱戏水、晒太阳、好奇眼、变色魔术师、优雅尾）：Lv.3 饥饿 `-10%`，Lv.5 饥饿 `-10%` 且产点 **`+5%`**。
     - *全缸在缸生物产点加速总和上限为 **`+25%`**。*

4. **温控设备与现实气象联动**

     - **夹缸静音降温扇**（`8` 生态点）：`-4°C` 稳态降温，封顶温度（苔原 `18°C`、鱼缸 `22°C`、雨林 `23°C`、沙地 `24°C`）；开启时蒸发率 `0.85×`。

   - **本地气象联动**：零系统权限弹窗，通过 IP 定位 + Open-Meteo 每 30 分钟静默获取室外实时气温，经室内微缓冲映射。
   - **随机小气候事件**：每 **`20~40 分钟`**随机触发，持续 **`15 分钟`**：林间小雨（`-4°C`，湿度 `+18%`）、暖阳斜照（`+4°C`，湿度 `-10%`）、深夜微凉（`-3°C`，湿度 `+6%`）、晨露微风（`-1°C`，湿度 `+8%`）。

## 五、经济系统与防刷机制

1. **生态点产出途径**
   - **挂机产点**：缸内必须存在**活体植物（非枯萎）或在缸生物**，且湿度达到产点阈值（苔原/雨林/鱼缸 **`≥35%`**，沙地 **`≥26%`**）。基础间隔 **`360s`/点**，适宜环境缩短至 **`240s`/点**。
   - **多缸产点递减系数**：第 1 缸 `100%`、第 2 缸 `80%`、第 3 缸 `65%`、第 4 缸 `55%`、第 5 缸起 `50%`。
   - **图鉴首次解锁**：植物 `+2` 点、基础动物 `+3` 点、稀有/高阶动物 `+5` 点。
   - **进食奖励**：生物在 `hunger ≥ 55.0` 且距上次领奖 `≥3 小时` 时进食奖励 `+1` 点。
   - **维护返点**：清理枯萎植物 `+1` 点/株；修剪非幼苗植物 `+1` 点/株。
   - **拆缸退点**：按 **`75%` 折旧**退还（缸体购置原价 + 已解锁摆件 + 已领养生物 + 已购温控设备之和 × `0.75` 向下取整），至少保留 1 口缸。

2. **防刷闭环机制**
   - **0 点击直发点数**：轻抚只加好感与性格被动，不直接掉落生态点。
   - **幼苗修剪 0 返点**：`sprout` 期修剪不返点，且冷启动 `15s` 脉冲每缸终身仅 1 次。
   - **进食节流**：`3 小时`/只冷却 + `hunger ≥ 55.0` 门槛。
   - **生物仓隔离**：收起至 `.stored` 的生物不消耗饥饿、不偷吃、不提供性格产点加成。
   - **防多缸无限膨胀**：多缸购置阶梯涨价（`+15`/口）+ 槽位产点递减（最低 `50%`）+ 离线结算上限 `8 小时`。
